# Event Registration

PHP/MySQL event listing, creation, student registration, and removal.

## Run

Import database/schema.sql into a new empty database. Copy database.example.php to database.local.php and edit settings. Open http://localhost/event_registration_app/.

## Scope

Schema reconstructed for this repository; fictional sample records. Create/register still need CSRF checks and access control.

See the [repository README](../README.md) for setup and attribution.
